Service Detail

OkiDev

OkiDevは、画像からwplace用のオーバーレイを生成し、登録済みのサーバー資料を参照して質問へ回答するDiscord Botです。翻訳、要約、履歴会話、コード相談にも対応しています。

Discord Bot

制作と資料確認をDiscordで支援

`/make overlay`で.wplaceファイルを生成し、`/ai`で用途別の文章処理を実行します。AIによる回答は、利用者が原資料を確認できるよう参照元を表示します。

Overview

OkiDevでできること

Overlay

オーバーレイを作る

画像とwplace URLを指定し、配置情報を含む.wplaceファイルをDiscordで生成します。

Knowledge

サーバー資料を調べる

登録済み資料から質問に関連する内容を検索し、参照元を示しながら回答します。

AI

文章と画像を処理する

文章、Discordメッセージ、画像の翻訳と要約に加え、履歴会話やコード相談を利用できます。

Commands

主なDiscordコマンド

Create

/make overlay

PNG、JPEG、GIF、WebPの画像から、指定したwplace座標へ配置するオーバーレイを生成します。

Search

/ai ask

サーバーのルールや案内など、AI Searchへ登録された資料を検索して質問に回答します。

Assist

/ai chat

利用者ごとの履歴を使って会話します。必要な場合だけ資料検索を有効にできます。
