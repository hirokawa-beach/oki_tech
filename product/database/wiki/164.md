## JR沖ノ鳥 沖央線

### 概要

沖央線（ちゅうおうせん）とは、沖ノ口から比海北ニュータウンまでを結ぶJR線である。

  

- JR 沖ノ鳥: 所有者・事業者
  - 沖央線 / ちゅうおうせん / Chuo Line: 沖ノ鳥旅客鉄道株式会社 / (第1種鉄道事業者)
- JR 沖ノ鳥: 国
  - 沖央線 / ちゅうおうせん / Chuo Line: 日本
- JR 沖ノ鳥: 所在地
  - 沖央線 / ちゅうおうせん / Chuo Line: 沖ノ鳥県
- JR 沖ノ鳥: 種類
  - 沖央線 / ちゅうおうせん / Chuo Line: 普通鉄道（在来線・幹線）
- JR 沖ノ鳥: 路線記号
  - 沖央線 / ちゅうおうせん / Chuo Line: JE
- JR 沖ノ鳥: 総距離
  - 沖央線 / ちゅうおうせん / Chuo Line: -km / （沖ノ口～フィリピン海北ニュータウン）
- JR 沖ノ鳥: 開業日
  - 沖央線 / ちゅうおうせん / Chuo Line: 2025年8月15日 / (～)
- JR 沖ノ鳥: 起点
  - 沖央線 / ちゅうおうせん / Chuo Line: 沖ノ口駅
- JR 沖ノ鳥: 終点
  - 沖央線 / ちゅうおうせん / Chuo Line: 比海北ニュータウン駅
- JR 沖ノ鳥: 駅数
  - 沖央線 / ちゅうおうせん / Chuo Line: 33
- JR 沖ノ鳥: 電報略号
  - 沖央線 / ちゅうおうせん / Chuo Line: -
- JR 沖ノ鳥: 軌道幅
  - 沖央線 / ちゅうおうせん / Chuo Line: 1,067 mm (狭軌)
- JR 沖ノ鳥: 電化方式
  - 沖央線 / ちゅうおうせん / Chuo Line: 直流1,500 V 架空電車線方式
- JR 沖ノ鳥: 線路数
  - 沖央線 / ちゅうおうせん / Chuo Line: 複線 / ※一部複々線
- JR 沖ノ鳥: 最高速度
