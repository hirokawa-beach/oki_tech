## JR沖ノ鳥 前島線

前島線（まえしません、英：Maesima Line）は、JRうるま駅から沖芝浦駅までを結ぶ、JR沖ノ鳥の路線である。  
駅ナンバリングは設定されていない。

  

### 概要

- JR 沖ノ鳥: 所有者・事業者
  - 前島線 / まえしません / Maesima Line: 沖ノ鳥旅客鉄道株式会社 / (第1種鉄道事業者)
- JR 沖ノ鳥: 国
  - 前島線 / まえしません / Maesima Line: 日本
- JR 沖ノ鳥: 所在地
  - 前島線 / まえしません / Maesima Line: 沖ノ鳥県
- JR 沖ノ鳥: 種類
  - 前島線 / まえしません / Maesima Line: 普通鉄道（在来線・幹線）
- JR 沖ノ鳥: 路線カラー
  - 前島線 / まえしません / Maesima Line: (里見線と同じ)
- JR 沖ノ鳥: 総距離
  - 前島線 / まえしません / Maesima Line: -km / （JRうるま～沖芝浦）
- JR 沖ノ鳥: 開業日
  - 前島線 / まえしません / Maesima Line: 2025年8月 日 / (～)
- JR 沖ノ鳥: 起点
  - 前島線 / まえしません / Maesima Line: JRうるま駅
- JR 沖ノ鳥: 終点
  - 前島線 / まえしません / Maesima Line: 沖芝浦駅
- JR 沖ノ鳥: 駅数
  - 前島線 / まえしません / Maesima Line: 10
- JR 沖ノ鳥: 電報略号
  - 前島線 / まえしません / Maesima Line: -
- JR 沖ノ鳥: 軌道幅
  - 前島線 / まえしません / Maesima Line: 1,067 mm (狭軌)
- JR 沖ノ鳥: 電化方式
  - 前島線 / まえしません / Maesima Line: 直流1,500 V 架空電車線方式
- JR 沖ノ鳥: 線路数
  - 前島線 / まえしません / Maesima Line: 複線
- JR 沖ノ鳥: 最高速度
  - 前島線 / まえしません / Maesima Line: 120 km/h

  

土休日には蟹田〜沖芝浦間を走る列車の設定はなく、全ての列車が蟹田駅で折り返す。つまり土休日に当該区間は運休する。

  

前島駅から西に分岐して(厳密には蟹田駅付近で分岐)前島港駅(貨物)に至る貨物線がある。
