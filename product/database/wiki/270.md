## JR沖ノ鳥 国連線

### 概要

　JG　 国連線（こくれんせん、英：Kokuren Line）とは、名所から新沖ノ鳥までを結ぶJR線である。  
路線ナンバリングは、　JG　

  

- JR 沖ノ鳥: 所有者・事業者
  - 国連線（こくれんせん） / Kokuren Line: 沖ノ鳥旅客鉄道株式会社 / (第1種鉄道事業者)
- JR 沖ノ鳥: 国
  - 国連線（こくれんせん） / Kokuren Line: 日本
- JR 沖ノ鳥: 所在地
  - 国連線（こくれんせん） / Kokuren Line: 沖ノ鳥県
- JR 沖ノ鳥: 種類
  - 国連線（こくれんせん） / Kokuren Line: 普通鉄道（在来線・幹線）
- JR 沖ノ鳥: 路線記号
  - 国連線（こくれんせん） / Kokuren Line: JG
- JR 沖ノ鳥: 総距離
  - 国連線（こくれんせん） / Kokuren Line: -km / （JR知鳥～新沖ノ鳥）
- JR 沖ノ鳥: 開業日
  - 国連線（こくれんせん） / Kokuren Line: 2025年8月15日 / (～)
- JR 沖ノ鳥: 起点
  - 国連線（こくれんせん） / Kokuren Line: 名所駅
- JR 沖ノ鳥: 終点
  - 国連線（こくれんせん） / Kokuren Line: 新沖ノ鳥駅
- JR 沖ノ鳥: 駅数
  - 国連線（こくれんせん） / Kokuren Line: 31
- JR 沖ノ鳥: 電報略号
  - 国連線（こくれんせん） / Kokuren Line: -
- JR 沖ノ鳥: 軌道幅
  - 国連線（こくれんせん） / Kokuren Line: 1,067 mm (狭軌)
- JR 沖ノ鳥: 電化方式
  - 国連線（こくれんせん） / Kokuren Line: 直流1,500 V 架空電車線方式
- JR 沖ノ鳥: 線路数
  - 国連線（こくれんせん） / Kokuren Line: 複線 / ※一部複々線
- JR 沖ノ鳥: 最高速度
  - 国連線（こくれんせん） / Kokuren Line: 130 km/h

  

かつて存在していたJR知鳥〜名所間は維持費用に見合わないほど利用者が少なかったため廃止された。
