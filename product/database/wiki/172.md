## JR沖ノ鳥 北マリアナ線

### 概要

　JH　 北マリアナ線（きたマリアナせん、英：Kita Mariana Line）とは、新沖ノ鳥から沖境までを結ぶJR線である。  
路線ナンバリングは、　JH　 である。

  

- JR 沖ノ鳥: 所有者・事業者
  - 北マリアナ線 / きたマリアナせん / Kita Mariana Line: 沖ノ鳥旅客鉄道株式会社 / (第1種鉄道事業者)
- JR 沖ノ鳥: 国
  - 北マリアナ線 / きたマリアナせん / Kita Mariana Line: 日本
- JR 沖ノ鳥: 所在地
  - 北マリアナ線 / きたマリアナせん / Kita Mariana Line: 沖ノ鳥県
- JR 沖ノ鳥: 種類
  - 北マリアナ線 / きたマリアナせん / Kita Mariana Line: 普通鉄道（在来線・幹線）
- JR 沖ノ鳥: 路線記号
  - 北マリアナ線 / きたマリアナせん / Kita Mariana Line: JH
- JR 沖ノ鳥: 総距離
  - 北マリアナ線 / きたマリアナせん / Kita Mariana Line: -km / （新沖ノ鳥～沖境）

- JR 沖ノ鳥: 起点
