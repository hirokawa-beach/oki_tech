# OkiMail Web サービス

source: okimail-local-implementation
updated: 2026-10-09
category: site
public_url: https://mail.wplaceoki.com/

## 概要

OkiMail の Web サイトは、発行済みメールアドレスの確認、メール作成、ブロック設定、問い合わせ、eml ファイルの閲覧に対応しています。

受信メールの Discord DM 転送とコマンドは、[OkiMail Bot 概要](../../bots/okimail/overview.md)を参照してください。

## 公開機能

ログインせずにサービス案内、メール機能案内、eml ビューアー、利用規約、プライバシーポリシー、運営者情報を閲覧できます。

公式サイト：

https://mail.wplaceoki.com/

## Discord ログインとユーザー設定

発行アドレスの確認、メール送信、ブロック設定、問い合わせの送信と履歴確認には Discord ログインが必要です。

[ユーザー設定](https://mail.wplaceoki.com/account/)では、本人に紐づく有効な発行アドレスとその種別を確認できます。

送信元メールアドレスのブロック追加、一覧確認、解除もできます。

Discord コマンドから変更したブロック設定も反映されます。

この画面から利用者自身がアドレスを発行または削除することはできません。

## メール作成と送信

[メール機能](https://mail.wplaceoki.com/mail/)から、ログイン後に送信画面へ進めます。

本人が所有する有効な発行アドレスを送信元にし、To、CC、BCC、件名、本文、添付を指定できます。

Web ではプレーンテキストに加えて HTML メールにも対応します。

HTML はリッチ編集、ソース編集、プレビューを切り替えられ、テキストの代替本文も必要です。

宛先は合計50件、件名は200文字、テキスト本文は4,000文字、添付は10個かつ合計3 MiB までです。

## 予約送信

送信機能が有効な環境では、1分後から7日後までの日時を指定して予約できます。

Web の予約日時は端末のタイムゾーンで入力します。

予約一覧から、送信処理が始まる前の予約を取り消せます。

内容を変更する場合は、取り消してから作成し直します。

送信控えは Discord DM へ送られます。

送信結果が不明な場合は、重複送信を避けるため自動で再送しません。

## アドレス発行申請と問い合わせ

[問い合わせ](https://mail.wplaceoki.com/contact/)から、アドレス発行申請やサービスに関する相談を送れます。

Discord でログインすると、自分の問い合わせ履歴と状態を確認し、運営者と返信をやり取りできます。

アドレスは運営者が申請内容を確認して発行します。

## eml ビューアー

[eml ビューアー](https://mail.wplaceoki.com/viewer/)は、PC やスマートフォンに保存した `.eml` を開くための公開ツールです。

ファイルは端末内だけで解析し、OkiMail へアップロードしません。

件名、送信元、宛先、CC、日時、本文、添付情報を確認できます。

HTML とプレーンテキストが両方ある場合は表示を切り替えられます。

外部画像は自動取得しません。

ファイル上限は 10 MiB で、暗号化されたメールや解析できないファイルなどは理由を示して拒否します。

## AI による案内と入力補助

外部 MCP と A2A は、サービス案内などの公開情報だけを読み取れます。

利用者のアカウント、メール本文、添付、問い合わせにはアクセスしません。

対応ブラウザの WebMCP では、ログイン済み画面でメール作成、予約取消、ブロック設定、問い合わせなどの入力を補助できます。

送信や設定変更は利用者が画面で確認して確定し、添付ファイルも本人が選択します。
