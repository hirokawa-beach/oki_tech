# OkiMusic Bot

source: okimusic-service
updated: 2026-08-05
category: bot
public_url: https://music.wplaceoki.com/

## 概要

OkiMusic Bot は、OkiMusic の楽曲を Discord のボイスチャンネルで再生し、Discord から楽曲を投稿できる Bot です。

曲やプレイリストを再生キューへ追加し、一時停止、再開、スキップ、リピートなどを Discord のコマンドで操作できます。

OkiMusic の公式サイトでは、公開曲の再生、Discord ロールに応じた限定曲の表示、プレイリストの作成、共有 URL の発行などができます。

公式サイト：

https://music.wplaceoki.com/

## 主な機能

- OkiMusic に登録された曲をボイスチャンネルで再生する
- プレイリストや共有 URL の曲を再生キューへ追加する
- 再生の一時停止、再開、スキップ、停止を行う
- 現在の曲と再生キューを確認する
- 曲単位またはキュー全体のリピートを設定する
- Discord に添付した音声ファイルを OkiMusic へ投稿する
- 曲の公開状態や対象ロールを投稿時に設定する
- 再生サーバーの稼働状態を確認する

## VC 再生の使い方

再生を始める利用者は、先にボイスチャンネルへ参加します。

`/play` で曲、プレイリスト、または OkiMusic の共有 URL を指定すると、Bot が同じボイスチャンネルへ参加して再生します。

Bot がすでにボイスチャンネルへ参加している場合、再生を操作できるのは Bot と同じチャンネルにいる利用者です。

曲やプレイリストの閲覧権限には、OkiMusic 上の公開状態と Discord ロールが反映されます。

## 再生コマンド

### /play

曲、プレイリスト、または共有 URL を再生キューへ追加します。

```text
/play item:<曲、プレイリスト、共有URL> [private:<表示設定>]
```

`item` には、曲名、アーティスト名、プレイリスト名、または OkiMusic の共有 URL を指定できます。

検索候補には、実行した利用者が閲覧できる曲とプレイリストだけが表示されます。

`private` を有効にすると、実行結果は本人だけに表示され、キュー内に依頼者名が表示されません。

### /pause

現在の再生を一時停止します。

```text
/pause [private:<表示設定>]
```

### /resume

一時停止した再生を再開します。

```text
/resume [private:<表示設定>]
```

### /skip

現在の曲をスキップします。

```text
/skip [private:<表示設定>]
```

1 曲を繰り返す設定中に実行すると、そのリピート設定は解除されます。

### /stop

再生を停止し、再生キューを空にします。

```text
/stop [private:<表示設定>]
```

Bot はボイスチャンネルに残ります。

### /leave

再生を停止して再生キューを空にし、Bot をボイスチャンネルから退出させます。

```text
/leave [private:<表示設定>]
```

### /queue

現在の曲に続いて再生されるキューを表示します。

```text
/queue [private:<表示設定>]
```

### /now

現在再生中の曲を表示します。

```text
/now [private:<表示設定>]
```

### /repeat

リピート方法を設定します。

```text
/repeat mode:<off|track|queue|reset> [private:<表示設定>]
```

- `off`：リピートを無効にする
- `track`：現在の曲を繰り返す
- `queue`：キュー全体を繰り返す
- `reset`：現在のリピート設定を初期状態へ戻す

### /server

再生サーバーの状態を表示します。

```text
/server [private:<表示設定>]
```

稼働状態、再生状態、ボイスチャンネル、再生担当ホストなどを確認できます。

## 楽曲の投稿

投稿を許可された Discord ロールの利用者は、`/upload` で音声ファイルを OkiMusic へ投稿できます。

コマンドは許可された Discord サーバー内でのみ利用できます。

著作権に関する注意事項を確認して `OK` ボタンを押すと、アップロードが始まります。

### /upload

```text
/upload file:<音声ファイル> [title:<曲名>] [artist:<アーティスト>] [visibility:<公開状態>] [original_lyricist:<作詞者>] [original_composer:<作曲者>] [arranger:<編曲者>] [lyrics:<歌詞カード>] [role1:<対象ロール>] ... [role5:<対象ロール>]
```

曲名を省略した場合は、音声ファイル名が曲名として使われます。

公開状態を省略した場合は非公開になります。

ロール限定を選ぶ場合は、対象ロールを一つ以上指定します。

対象ロールは五つまで指定できます。

## 公開状態

- **公開**：未ログインの利用者を含め、誰でも閲覧と再生ができる
- **限定公開**：通常の一覧には表示されず、投稿者または共有 URL を知っている利用者がアクセスできる
- **非公開**：投稿者本人だけが通常利用上で確認できる
- **ロール限定**：指定した Discord ロールを持つ利用者だけが閲覧と再生をできる

## 対応音声形式

OkiMusic は、次の音声形式の投稿に対応しています。

- mp3
- m4a
- aac
- ogg
- opus
- webm
- flac
- wav

1 曲あたりのアップロード上限は 50.0 MiB です。

## 利用上の注意

投稿する曲について、著作権上の許諾を得て掲載できるかどうかを OkiMusic 側では確認していません。

投稿者は、注意事項を確認し、掲載に必要な権利を持つ音源だけをアップロードしてください。

投稿停止の対象になっている利用者は、Web と Discord のどちらからもアップロードできません。

再生コマンドが利用できる Discord サーバーと、楽曲を投稿できるロールは運用設定によって異なります。
