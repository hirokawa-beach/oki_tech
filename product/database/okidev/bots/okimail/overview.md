# OkiMail Bot

## 概要

OkiMail Bot は、発行済みアドレスで受信したメールを Discord DM へ転送し、コマンドからメール送信、予約送信、ブロック設定を行える Bot です。

Web 版の操作は、[OkiMail Web サービス概要](../../sites/okimail/overview.md)を参照してください。

## 受信メールの転送

メールが届くと、送信元、宛先、CC、件名、本文抜粋を利用者の DM へ自動転送します。

長いメールの全文は、添付された元メールの `.eml` で確認してください。

DM の受信設定や Bot と連絡できる状態によって、転送に失敗する場合があります。

Bot のユーザー ID は `1446422325594554482` です。

## 添付ファイル

元メールが 10 MiB 以下の場合、`original_mail.eml` として添付します。

通常添付の抽出対象は、添付指定があり Base64 で格納されたパートです。

各ファイルは 10 MiB 以下、送信するファイルは元メールを含め最大10個です。

元メールを添付した場合、通常添付は最大9個になります。

容量、個数、メール構造などによって一部が省略され、その旨が DM に表示される場合があります。

埋め込み画像がすべて独立した添付として転送されるわけではありません。

## /block

指定した送信元から自分宛てに届くメールをブロックします。

```text
/block email:<送信元メールアドレス>
```

設定は Discord ユーザー ID 単位で共通し、本人の複数アドレスへ適用されます。

Web のユーザー設定と同じ設定を使います。

Gmail ではピリオドや `+` 以降の別名などを正規化して比較します。

## /unblock

指定した送信元のブロックを解除します。

```text
/unblock email:<送信元メールアドレス>
```

## /id

Discord ユーザー ID に紐づく有効な発行アドレスを表示します。

```text
/id userid:<DiscordユーザーID>
```

一般利用者が確認できるのは自分の ID だけです。

許可された管理者は、指定サーバー内で別の利用者の ID も確認できます。

## /send

本人が所有する有効な OkiMail アドレスからメールを送信します。

```text
/send sender:<自分のアドレス> to:<宛先> subject:<件名> body:<本文> [cc:<宛先>] [bcc:<宛先>] [send_at:<予約日時>] [attachment_1:<ファイル>] ... [attachment_10:<ファイル>]
```

コマンドの登録と送信機能が有効な環境で利用できます。

To、CC、BCC は複数アドレスをカンマで区切れます。

宛先は合計50件、件名は200文字、本文は4,000文字、添付は10個かつ合計3 MiB までです。

Discord ではプレーンテキスト本文だけに対応します。

予約日時は日本時間の `YYYY-MM-DD HH:mm` で指定し、1分後から7日後まで予約できます。

送信後は控えを DM へ送ります。

メール送信に成功しても DM 控えに失敗した場合、控えだけが保留になり、メール自体は再送されません。

コマンドの結果は原則として実行した本人だけに表示されます。

## アドレス発行

一般利用者向けのアドレス発行コマンドは現在の登録対象に含まれていません。

発行を希望する場合は、[公式サイトの問い合わせ](https://mail.wplaceoki.com/contact/)などの指定窓口から申請してください。

運営者が申請を確認し、管理画面で発行と Discord ユーザー ID の紐づけを行います。

## 利用上の注意

メールの到達、完全な転送、指定時刻どおりの予約送信、継続提供は保証されません。

送信結果を確認できない障害では、重複送信を避けるため自動再送しません。

迷惑メール、詐欺、なりすましなどの禁止用途と利用制限は、[利用規約](https://mail.wplaceoki.com/terms/)を確認してください。

一般利用者向け SMTP、IMAP、POP 接続は提供していません。
